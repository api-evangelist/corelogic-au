# CoreLogic Australia (Cotality)

> Australia's dominant independent property data, analytics and valuation provider, trading as
> Cotality since the 2025 global rebrand and operating the RP Data platform through RP Data Pty
> Ltd. It aggregates state land-registry and valuer-general records, agent and portal listing
> campaigns, auction results and rental campaigns into a single property spine, then sells that
> spine to banks, mortgage brokers, valuers, insurers, agents and government. The API surface is
> genuinely developer-facing but commercially licensed: a self-serve Backstage developer portal at
> developer.corelogic.asia issues sandbox OAuth clients against a deliberately restricted
> evaluation dataset, while every production host in the *.api.cotality.com.au family requires a
> signed commercial data licence.

Generated by API Evangelist on 2026-07-26 from the public Cotality developer surface. No
provider-published llms.txt exists (developer.corelogic.asia/llms.txt returns the portal's
single-page-app HTML shell, not text).

## Key facts for agents

- Auth: OAuth 2.0 `client_credentials`, HTTP Basic client auth, JWT bearer on every request, TLS
  1.2 minimum. Read expiry from the JWT `exp` claim — token lifetime is not fixed.
- Authorisation is **claim-based** (`roles`, `geo_codes`, `authorities` in the JWT), not
  scope-based. Requesting a scope will not widen access.
- Join key is an opaque numeric **CoreLogic property identifier**, resolved from free text by the
  Address Matcher. It is NOT a RESO UPI, and it is not permanent.
- No RESO, no OData, no GraphQL, no AsyncAPI, no webhooks outside PSX, no public OpenAPI, no first
  party SDK, no CLI, no changelog, no status page for Australia.
- Three environments: sandbox (`api-sbox.corelogic.asia`, self-serve), UAT
  (`*.api-uat.cotality.com.au`), production (`*.api.cotality.com.au`). Tokens do not cross them.
- Errors are `{"messages":[{"type":"ERROR","message":"..."}]}` — not RFC 9457.
- No idempotency contract exists on this surface.

- [Search API](https://developer.corelogic.asia/address_matcher): address matching, radius and location search, last-sale and on-the-market flavours — `https://search.api.cotality.com.au`
- [AVM API](https://developer.corelogic.asia/apis): IntelliVal static, historical, live and banded automated valuations — `https://avm.api.cotality.com.au`
